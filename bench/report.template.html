Email API benchmark: Node vs Bun vs Go vs Rust

The same Resend-style POST /emails service in TypeScript (on Node and on Bun), Go and Rust, each in a 1 CPU / 2 GB container. Byte-identical behaviour verified by a parity harness (67/68 fixtures). Medians of 3 runs. Latency, CPU and memory are measured with all servers at the same fixed load.

Table view (all runs)

Payloads: small = 2 KB transactional email (HTML→text), large = 730 KB newsletter with a 150 KB serialized Node Buffer and a 100 KB base64 attachment, batch = 50 small emails. Medians of 3 interleaved runs on an Apple M4 under OrbStack; hover a bar for the min–max across runs.
